# Dr. R. Senthilkumar — Academic Portfolio

A responsive academic portfolio for Dr. R. Senthilkumar, Assistant Professor in the Department of Computer Science and Engineering at Hindusthan Institute of Technology, Coimbatore.

The portfolio presents the supplied academic record, including:

- Academic profile, research index, areas of specialization, and memberships
- Education and academic appointments
- AICTE-sponsored research and ATAL programme
- NPTEL achievements, certification courses, and IIT faculty development programmes
- Journal publications, books, book chapters, and conference contributions
- Patents, awards, teaching subjects, and community activities

## Run locally

```bash
node server.js
```

Open `http://localhost:3000/` in a browser.

## Project structure

```text
portfolio/
├── index.html       # Portfolio sections and navigation
├── css/style.css    # Responsive layout and styling
├── js/data.js       # Academic profile and résumé data
├── js/app.js        # Rendering and interface behavior
├── assets/profile/  # Profile portrait
└── server.js        # Local static file server
```
