# Dr. R. Senthilkumar — Academic & Innovation Portfolio Website

A modern, responsive, and prestigious academic portfolio website for **Dr. R. Senthilkumar**, Associate Professor at **Hindusthan Institute of Technology, Coimbatore**.

Designed faithfully to match the reference design layout with deep forest-green accents, golden capsule navigation pills, white rounded framing cards, interactive high-definition modals, and **zero empty space / letterboxing**.

## 🚀 How to Run & View the Website

The website is actively served via the zero-dependency Node server:
```bash
node server.js
```
Open **`http://localhost:3000/`** in your browser to view the live portfolio!
